* Higher Order Functions - (Part I)
** Why we need higher order functions
- Short and concise
- Clear and readable
- Makes debugging easy - when we use the known idioms
- Enables functional style of Programming with immutable values
- Leveraging Unix Style Functions
  - Write Functions which do one thing well
  - Helps Wiring them to achieve what the application requires
** Idioms using Python Lists
*** all
- Return true, if all the elements are truthy
#+begin_src python
  # {} is falsy
  all([True, 1, {}])
  ## False
#+end_src
*** any
- Return true, if any of the elements are truthy
#+begin_src python
  any([True, 1, {}])
  ## True
#+end_src
*** Maximum / Minimum in a list
- Return the maximum / minimum elements in a list
#+begin_src python
  xs = [3, 2, 4, 1, 5]

  max(xs)
  ## 5

  min(xs)
  ## 1

  # inside a subset
  max(*xs[2:4])
  ## 4
#+end_src
*** List Comprehensions - another way of doing map, filter
**** Initializing
#+begin_src python
  from dataclasses import dataclass

  @dataclass
  class Person:
      name: str
      dept: str

  p1 = Person('alice', 'engg')
  p2 = Person('bob', dept='sales')
  p3 = Person('charlie', dept='HR')

  people = [p1, p2, p3]
#+end_src
**** Map
#+begin_src python
  # [people] -> [names]
  names = [p.name for p in people]
  ## ['alice', 'bob', 'charlie']
#+end_src
**** Convert scores to grade bucket
#+begin_src python
  def bucket(grade):
      return grade // 10 * 10

  grades = [79, 25, 31, 72, 60, 10, 65, 32, 100, 63, 36, 57, 0]
  [bucket(g) for g in grades]
  ## [70, 20, 30, 70, 60, 10, 60, 30, 100, 60, 30, 50, 0]
#+end_src
**** Creating a zero element list
#+begin_src python
  # has the same length as [1, 2, 3, 4]
  zeros = [0 for _ in [1, 2, 3, 4]]
  ## [0, 0, 0, 0]
#+end_src
**** Creating Increasing Pairs
#+begin_src python
  increasing_pairs = [(x, y)                       # only pairs with x < y,
                    for x in range(4)           # range(lo, hi) equals
                    for y in range(x + 1, 4)]   # [lo, lo + 1, ..., hi - 1]
  ## [(0, 1), (0, 2), (0, 3), (1, 2), (1, 3), (2, 3)]
#+end_src
**** Filter
#+begin_src python
  # filter - only HR dept
  hrs = [p.name for p in people if p.dept == "HR"]
  ## ['charlie']
#+end_src
**** Filter only the even numbers
#+begin_src python
  even_nums = [x for x in range(5) if x % 2 == 0]

#+end_src
**** Reduce
#+begin_src python
  from functools import reduce

  joined = reduce(lambda x, y: x + y, [1, 2, 3, 4, 5])
  ## 15
  joined = reduce(lambda x, p: x + ", " + p.name, people, "")
  ## ', alice, bob, charlie'
#+end_src
*** Using Walrus Operator in list comprehension
**** Without walrus operator
#+begin_src python
  def inc(x):
      return x + 1

  xs = [-5, -2, -1, 6, 7, 9, -3, -4, 3]

  [inc(x) for x in xs if inc(x) > 0]
  ## [7, 8, 10, 4]
#+end_src
**** Using Walrus Operator
#+begin_src python
  # avoids recomputing inc(x) twice
  [y for x in xs if (y := inc(x)) > 0]
  ## [7, 8, 10, 4]
#+end_src
